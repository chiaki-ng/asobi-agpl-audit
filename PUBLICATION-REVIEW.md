# Local publication review

Prepared October 7, 2026. The project maintainer authorized private GitHub staging under chiaki-ng/asobi-agpl-audit for review. Public visibility is not authorized by this staging step. No complaint or issue update has been posted.

This repository starts from a fresh snapshot, followed by review updates. It has no private audit ancestry, reflogs or copied .git directory. Commits are authored as Street Pea using the GitHub noreply address, so no private contact address is exposed. Commits made with AI assistance carry a Co-Authored-By line. Review signing settings before any public release.

The evidence set was built by explicit selection, not by deleting a few files from the private repository. Raw app archives/executables, account material, private correspondence, screenshots and image metadata, full web captures/headers, bulk decompilations, device/network identifiers and machine paths were excluded. Full function hex blobs were removed from the selected Portal integration JSON; output hashes were regenerated. Native excerpts and upstream attribution are retained only where they support the described findings.

Before publication, review FINDINGS.md, EVIDENCE.md and the three unsent drafts. Fill personal identity/certification fields only in a private submission copy. Select reuse licensing for original audit prose/tools if desired; upstream license documents do not license the entire audit. The strongest unresolved matters are recorded alongside the affirmative findings.

For an Apple submission, provide a self-contained complaint and selected key exhibits, and use the eventual public repository as a supporting reference. For a GitHub issue, summarize the findings/limits and link the public repository. Avoid filing a bare repository link without a version-specific explanation. Public complaint drafts should keep personal contact details blank.

`python3 tools/verify_public.py` checks exact manifest coverage, text-only types, local links and specified exposure patterns. It is a reproducible check, not a guarantee about all possible privacy or legal questions. No original private repository needs to become public to publish this snapshot.

Input-provider names, archive filenames identifying preparation tools, and the input-preparation process are omitted. Input hashes and the limited-authentication qualification remain. This omission does not assert independently verified instruction authenticity.
